项目名称：CameraUtils
项目简介：Utils code for camera HAL use
运行环境：windows11 OS + visual studio 2022, cmake 构建
依赖环境
系统环境变量 PATH变量 配置ffmpeg + opencv：
D:\ThirdPartyLib\ffmpeg\ffmpeg_windows\ffmpeg-master-latest-win64-gpl-shared\bin
D:\ThirdPartyLib\opencv\opencv_windows\install\x64\vc17\bin

opencv库的cmake路径
D:\ThirdPartyLib\opencv\opencv_windows\install\OpenCVConfig.cmake

手动下载rapids-cmake，解压到如下路径，解决内网CMake 在下载 rapids-cmake 时 SSL 验证失败问题：
D:/ThirdPartyLib/rapids-cmake
