# 双目立体匹配（Stereo Matching）学习笔记

## 原理

双目立体匹配在**已极线校正**的左右两图上，找到每个像素在另一图中的对应点，得到**视差图**。

视差与深度的关系（三角测距）：

```
depth = f · b / disparity
```

- f 是焦距，b 是基线（两相机间距），disparity 是视差（对应点的水平像素差）。
- 视差大 = 近，视差小 = 远。

OpenCV 实现：
- **StereoBM**（块匹配）：简单快速，精度低。
- **StereoSGBM**（半全局匹配）：用动态规划 + 多方向代价聚合，精度高，是默认选择。

## 背景

视差图是双目深度估计的核心。给定校正后的左右图，SGBM 逐像素找最佳匹配（最小化匹配代价），
输出视差图，再换算深度。

## 解决的问题

| 技术 | 解决的问题 |
|---|---|
| 视差估计 | 从左右图求逐像素视差 |
| 视差转深度 | 视差 → 深度（三角测距） |

## 效果

- 对结构纹理（真实场景），SGBM 能得较精确视差。
- 视差→深度是确定性的反比关系（已知 f/b 时）。

## 局限

- 依赖**纹理**：纯色/重复纹理区域匹配失败（视差为负/无效）。
- 依赖**极线校正质量**：校正不准 → 匹配失败。
- 遮挡区域无法匹配（左图可见右图不可见）。
- SGBM 参数多（numDisparities/blockSize/P1/P2/uniqueness），需调参。
- 视差 0（无穷远）或无效（-1）需防护。

## 后续改良

- **深度学习立体匹配**（PSMNet/RAFT-Stereo）：精度远超传统，是当前主流。
- **多尺度 SGBM + 后处理**：视差图滤波（WLS 滤波）平滑。
- **主动深度**（结构光/ToF）：无纹理也能测深。

## 实际工程使用情况

- **双摄虚化**：视差 → 深度 → 背景虚化（第 12 章大 demo）。
- **双目/双摄深度**：深度图估计。
- **自动驾驶**：双目测距。

## 对硬件的额外诉求

- SGBM 是计算密集（逐像素代价 + 多方向聚合），CPU 上较慢，GPU 可加速。
- 手机上双摄深度在 ISP/NPU 上硬件加速，或改用主动深度方案。
