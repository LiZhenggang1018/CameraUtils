# PnP（Perspective-n-Point）学习笔记

## 原理

PnP 从 **n 个 3D 点（世界坐标）+ 对应的 2D 投影点（像素坐标）+ 已知内参 K** 求解相机位姿（R, t）。

给定 3D 点 Xᵢ 与 2D 点 xᵢ，满足投影方程：

```
s xᵢ = K [R|t] Xᵢ
```

求解方法：
- **P3P**（3 点）：最小解，3 点 + 1 验证点，有多解需消歧。
- **EPnP**（Efficient PnP）：非迭代，快且鲁棒，OpenCV `SOLVEPNP_EPNP`。
- **ITERATIVE**（迭代优化）：以初值做 Levenberg-Marquardt 最小化重投影误差，OpenCV `SOLVEPNP_ITERATIVE`。

`cv::solvePnP` 返回 rvec（旋转向量）+ tvec（平移向量），用 `Rodrigues` 转成 R。

## 背景

PnP 与对极几何互补：对极几何（第 11 章）从**2D-2D** 求位姿（尺度未知），PnP 从**3D-2D** 求位姿
（尺度已知）。它是有地图（已知 3D 点）时的定位方法，是 SLAM、AR、相机定位的核心。

## 解决的问题

| 技术 | 解决的问题 |
|---|---|
| PnP | 从 3D-2D 对应求相机位姿 |

## 效果

- 已知精确 3D 点时，位姿精度高（重投影误差可达 1e-5 量级）。
- 是 AR 注册、视觉定位、SLAM 重定位的标准方法。

## 局限

- **退化场景**：3D 点共面时 PnP 退化（需非共面点）。
- 依赖 3D 点精度（地图误差 → 位姿误差）。
- 需足够匹配点（≥4，实际需更多以抗噪）。

## 后续改良

- **RANSAC + PnP**：鲁棒抵抗错误 2D-3D 匹配（`solvePnPRansac`）。
- **EPnP + 优化**：EPnP 初值 + 迭代精化，精度与速度兼顾。
- **多相机 PnP**：多相机联合位姿估计。

## 实际工程使用情况

- **AR**：已知 marker/地图点求相机位姿，叠加虚拟内容。
- **SLAM**：地图点匹配后的位姿估计（跟踪线程）。
- **相机定位**：视觉重定位。

## 对硬件的额外诉求

- PnP 是小型矩阵运算 + 迭代优化，算力低，可实时。
- 依赖前序特征匹配 + 3D 地图存储。
