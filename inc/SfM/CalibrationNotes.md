# 相机标定（Camera Calibration）学习笔记

## 原理

相机标定求解**内参矩阵 K**（焦距 fx/fy、主点 cx/cy）与**畸变系数**（径向 k1/k2/k3、切向 p1/p2）。

内参 K 把相机坐标系 3D 点映射到像素坐标：

```
s [u]   [fx  0  cx] [X]
  [v] = [ 0 fy  cy] [Y]
  [1]   [ 0  0   1] [Z]
```

**张正友标定**（1998，OpenCV `calibrateCamera`）：拍摄多张已知几何的棋盘（每个内角点的 3D 坐标已知），
检测棋盘角点（`findChessboardCorners`），利用「棋盘平面上的点满足单应」约束，先估单应，再从中解出
内参，最后优化畸变与外参。

## 背景

标定是所有几何视觉（配准、拼接、深度、SLAM、AR）的前置步骤——不知道内参和畸变，就无法把像素坐标
换算成真实几何关系。

## 解决的问题

| 技术 | 解决的问题 |
|---|---|
| 内参标定 | 建立像素 ↔ 相机坐标的映射 |
| 畸变标定 | 校正镜头径向/切向畸变 |

## 效果

- 标定后内参精确（合成数据可完美恢复真值）。
- 畸变校正后直线不再弯曲（去畸变 `undistort`）。

## 局限

- 需要多张不同姿态的棋盘图，姿态变化不足会导致标定退化。
- 棋盘角点检测质量影响精度（模糊、过曝、运动模糊会退化）。
- 只标定针孔模型；鱼眼/广角需专用模型（`fisheye::calibrate`）。

## 后续改良

- **亚像素角点精化**（`cornerSubPix`）：提升角点精度。
- **鱼眼模型**：广角镜头用 `fisheye` 模块。
- **在线标定 / 自标定**：无标定板，从场景运动自标定。
- **多相机联合标定**：双摄/多摄的外参（相对位姿）标定。

## 实际工程使用情况

- **多摄标定**：手机多摄像头的内参 + 相对外参标定（第 11~12 章双摄虚化的前提）。
- **AR / 视觉定位**：标定是基础。
- **去畸变**：几乎所有影像管线的预处理。

## 对硬件的额外诉求

- 标定是离线/一次性操作，算力不敏感。
- 去畸变（`undistort`/`remap`）在 ISP 上硬件加速。
