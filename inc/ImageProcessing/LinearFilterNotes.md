# 线性滤波（Linear Filtering）学习笔记

## 原理

线性滤波是图像处理最基础的操作：输出图像每个像素，是其邻域内像素的**加权和**。数学上就是
**卷积**（更准确地说是相关，OpenCV 的 `filter2D` 默认不做核翻转）：

```
dst(x, y) = Σ_{i,j} K(i, j) · src(x + i, y + j)
```

其中 `K` 是卷积核。因为输出是输入的线性组合，故称"线性"滤波。核的不同取值决定了滤波效果。

## 背景

线性滤波是几乎所有图像处理流程的地基。它在频率域上对应**滤波**（低通＝模糊、高通＝锐化/边缘），
在空间域上是**邻域加权平均**。理解了核的形状，就理解了绝大多数滤波器的本质。

## 解决的问题

| 核 | 作用 | 解决的问题 |
|---|---|---|
| 均值核（全 1） | 平滑/模糊 | 去噪声（但会模糊边缘） |
| 高斯核 | 加权平滑 | 更自然的模糊，符合人眼与噪声模型 |
| 拉普拉斯/锐化核 | 锐化 | 增强边缘、提升观感清晰度 |
| Sobel 核 | 一阶导数 | 边缘检测（x/y 方向梯度） |

## 效果

- **高斯模糊**：权重按高斯分布衰减，中心权重高、远处低，平滑且保留一定结构，比均值模糊"干净"。
- **锐化**（unsharp 掩膜）：`sharp = src + amount·(src − blur)`，用高通分量强化边缘。
- **Sobel**：`Gx` 检测垂直边缘（水平梯度），`Gy` 检测水平边缘（垂直梯度）。

## 局限

- 线性滤波对**所有位置一视同仁**：去噪的同时必然模糊边缘，锐化的同时必然放大噪声——这是
  线性滤波的根本矛盾（保边与去噪不可兼得），也是后面非线性滤波（中值/双边）存在的理由。
- 高斯核的 σ 与核尺寸需要匹配（σ 太大而核太小会截断；σ=0 时由 OpenCV 从核尺寸反推）。
- 核尺寸必须为奇数，偶数无对称中心、语义模糊。

## 后续改良

- **均值 → 高斯**：引入空间权重，减少振铃与块状感。
- **高斯 → 双边滤波（bilateral）**：在空间权重外再引入**灰度相似度权重**，做到保边去噪，突破
  线性滤波的矛盾（见"非线性滤波"模块）。
- **空域 → 频域**：大核卷积可用 FFT 加速（`cv::dft`），复杂度从 O(N·K²) 降到 O(N log N)。
- **可分离核**：高斯/Sobel 可分解为两个一维核的级联，从 O(K²) 降到 O(K)（`cv::sepFilter2D`）。

## 实际工程使用情况

- **手机多帧降噪**：对齐后的多帧在金字塔各层做高斯加权融合。
- **锐化**：拍照后处理（unsharp mask / 细节增强）的标配。
- **边缘检测**：Sobel 是 Canny 边缘检测（第 3 章后续）的第一步梯度估计。
- 几乎所有需要"预平滑"或"后处理"的管线都会用到线性滤波。

## 对硬件的额外诉求

- 线性滤波是**访存密集型**操作（每个输出像素要读 K² 个输入像素），对内存带宽敏感。
- 大核高斯在手机 NPU/GPU 上通常走**可分离核 + SIMD**，CPU 上 OpenCV 已做多线程并行（TBB/IPP）。
- 相比后续的重活（光流、深度），线性滤波算力诉求低，瓶颈在带宽而非算力。
