# 渐晕校正（Vignetting Correction）学习笔记

## 原理

**渐晕（Vignetting / 暗角）**是镜头成像时，图像**边缘/角落比中心暗**的现象。成因有两类：
1. **光学渐晕**：边缘光线被镜筒遮挡，入射角大时光量减少。
2. **自然渐晕**：cos⁴ 定律——边缘像素相对光轴倾斜，照度按 cos⁴θ 衰减。

常见模型用**径向多项式**描述衰减：

```
I(r) = I₀ · (1 - a·r² - b·r⁴ - ...)
```

其中 r 是归一化半径（中心 0，角落 1）。**校正**就是除以这个衰减因子（乘性增益）：

```
I' = I / (1 - a·r² - b·r⁴)
```

## 背景

渐晕在广角镜头、大光圈下更明显。拼接时，相邻图各自有暗角，会在重叠区产生周期性亮度起伏，
所以渐晕校正是曝光补偿的重要补充（OpenCV `Stitcher` 有 `VignettingEstimator`）。

## 解决的问题

| 技术 | 解决的问题 |
|---|---|
| 径向衰减模型校正 | 消除镜头暗角，使亮度均匀，利于拼接 |

## 效果

- 边缘亮度提升，图像亮度均匀。
- 拼接时重叠区亮度起伏消失。

## 局限

- 模型参数（a、b）需标定（用均匀灰场标定，或从多图重叠区估计）。
- 过度校正会放大边缘噪声（增益 > 1 处 SNR 下降）。
- 只校正径向对称的暗角，非对称渐晕需更复杂模型。

## 后续改良

- **高阶多项式**：更精确描述复杂镜头。
- **查表校正（LUT）**：标定后存增益表，运行时查表，速度快。
- **ISP 内置**：现代手机 ISP 在 RAW 域直接做渐晕校正（与去噪、白平衡联合）。

## 实际工程使用情况

- **全景拼接**：渐晕校正与曝光补偿配合（OpenCV `Stitcher`）。
- **相机标定**：径向畸变 + 渐晕联合标定。
- **手机 ISP**：渐晕校正是成像管线标准步骤。

## 对硬件的额外诉求

- 增益是逐像素乘，可在 ISP/GPU 上高效完成。
- 若在 RAW 域校正，可与去噪、白平衡合并，减少额外开销。
