# SIFT（Scale-Invariant Feature Transform）手写实现学习笔记

## 原理

SIFT 是 David Lowe 于 1999 年提出、2004 年完善的一个**局部特征**算法，目标是让同一个物理点在不同
图像（不同尺度、旋转、光照、视角）下都能产生「相似」的描述子，从而可靠匹配。它把整个流程拆成四个
前后相继的阶段：

```
灰度图 I
  │
  ├─ 阶段 1：尺度空间极值检测（DoG）
  │     L(x,y,σ) = G(x,y,σ) ∗ I
  │     DoG = L(kσ) − L(σ)      ← 用相邻高斯差近似尺度归一化 Laplacian
  │     在 DoG 金字塔的 3×3×3 邻域找极值（极大/极小）
  │
  ├─ 阶段 2：关键点精确定位
  │     对 DoG 做三元二次 Taylor 展开，解 ∂D/∂x=0 得亚像素偏移 x̂
  │     剔除两类不稳定点：低对比度（|D(x̂)| < 阈值）、边缘响应（Hessian 曲率比）
  │
  ├─ 阶段 3：方向分配
  │     关键点邻域梯度方向做 36 bin 加权直方图（高斯窗）
  │     峰值 = 主方向；≥80% 峰值 = 辅方向（同一位置生成多个关键点）
  │
  └─ 阶段 4：描述子生成（128 维）
        以主方向旋转坐标系，取 16×16 邻域，分 4×4 子块
        每子块 8 方向梯度直方图 → 4×4×8 = 128 维
        L2 归一化 → 截断 0.2 → 再归一化
```

## 背景

在 SIFT 之前，特征检测（Harris 角点、Hessian 斑点）与描述匹配是割裂的，且都**没有尺度不变性**——
同一目标在不同距离下成像尺寸不同，特征就会失配。SIFT 第一次把「尺度不变 + 旋转不变 + 鲁棒描述」
统一进一条完整管线，成为后续所有局部特征（SURF/ORB/AKAZE/BRISK）对标与改进的基准。

## 解决的问题

| 不变性 | SIFT 的手段 |
|---|---|
| 尺度不变 | DoG 尺度空间跨 octave/interval 找极值，关键点自带尺度 σ |
| 旋转不变 | 梯度方向直方图主方向 + 描述子旋转到主方向坐标系 |
| 光照不变（线性） | 梯度幅值 L2 归一化 |
| 光照不变（非线性） | 归一化后截断 0.2 再归一化 |
| 定位精度 | 亚像素 Taylor 展开 + 低对比度/边缘响应剔除 |

## 效果

- 精度最高、最鲁棒，是配准/拼接/标定的标杆。
- 计算慢：浮点描述子 + 复杂金字塔 + 多方向，无法实时。

## 局限

- **计算量大**：DoG 金字塔多次高斯卷积 + 每个关键点直方图 + 128 维浮点描述。
- **描述子维度高**：128 维 float，存储与 L2 匹配开销大。
- **专利**（原 SIFT 有专利保护，本实现仅作学习用途）。
- **对纹理依赖**：平坦区域无稳定极值，低纹理场景特征稀疏。

## 后续改良（后续算法如何在此之上改进）

- **SURF**：积分图 + Hessian 行列式加速检测，Haar 小波替代梯度直方图，仍是浮点但更快。
- **ORB**：多尺度 FAST（更快检测）+ 灰度质心法求方向 + 二进制 BRIEF 描述子 + Hamming 距离，
  把精度换成极致速度（SLAM/EIS 标配）。
- **AKAZE**：用非线性扩散（保边）替代线性高斯金字塔，边缘处精度更高；M-LDB 二进制描述。
- **深度学习特征**（SuperPoint/D2-Net/LoFTR）：直接学习检测+描述，现代 SfM/SLAM 逐渐替代手工特征。

## 实际工程使用情况

- **离线高精度配准、图像拼接、相机标定**：SIFT 是首选（精度优先，速度其次）。
- **实时配准 / EIS / SLAM**：ORB 是算力受限场景标配。
- **手机影像**：多摄对齐/标定/拼接离线流程仍常用 SIFT；实时预览用 ORB/AKAZE。

## 对硬件的额外诉求

- SIFT 浮点运算 + 多尺度卷积，CPU 上偏慢，GPU/NPU 可显著加速。
- 描述子匹配（L2 + FLANN）在大特征量下是瓶颈，需近似最近邻或专用加速。

## 本工程手写实现与 cv::SIFT 的差异

本实现追求「读懂原理」，用**可读性优先**的朴素写法，与 OpenCV 生产级实现有若干有意取舍：

| 维度 | 本实现 | cv::SIFT |
|---|---|---|
| 亚像素定位 | 有（DoG Taylor 展开 + 精化对比度二次剔除，非迭代） | 完整 Taylor 展开 + 迭代精化 |
| 描述子三线性插值 | 未做（bin 直接取整） | 三线性插值分配到相邻 bin |
| 尺度空间预平滑 | 从零累计（略慢） | 精确 sigma 管理与再抽样 |
| 空间非极大值抑制 | 有（`nmsWindowSize` 贪心窗口，缓解大图关键点过多） | 有（响应排序 + 空间窗口） |
| 性能 | 朴素循环，慢 | 高度优化 |

因此**关键点位置/描述子与 cv::SIFT 不逐位一致**，测试采用「数量同量级 + 旋转/尺度不变性成立」的
语义级交叉验证，而非数值精确比对。

## 关键参数

| 参数 | 默认 | 含义 |
|---|---|---|
| `nOctaveLayers` | 3 | 每 octave 间隔数（interval），影响尺度采样密度 |
| `contrastThreshold` | 1.0 | 低对比度关键点剔除阈值（DoG 响应绝对值）。**本实现 DoG 未归一化，故高于 Lowe 论文的 0.04**；调大该值可显著减少关键点数量 |
| `edgeThreshold` | 10.0 | 边缘响应剔除曲率比 r |
| `sigma` | 1.6 | 尺度空间基础高斯 sigma |
| `nmsWindowSize` | 5 | 空间非极大值抑制窗口边长（奇数），同一 (octave, layer) 内按响应贪心保留，值越大保留越少 |

> **关键点数量调节**：`contrastThreshold` 是比 `nmsWindowSize` 更有效的杠杆（本实现 DoG 未归一化，
> 阈值 0.04 会在大图上产生数十万关键点）。实测 5500×7333 图：`ct=1.0,nms=5` 约 10.7 万、
> `ct=2.0` 约 6 万、`ct=3.0,nms=15` 约 3.3 万。
