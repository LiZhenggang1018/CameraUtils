# 局部特征（Local Feature）学习笔记

## 原理

局部特征 = 关键点检测 + 描述子。描述子把关键点周围的局部图像块编码成一个**向量**，使同一物理点
在不同图像（不同视角/尺度/光照）下产生的描述子**相似**，从而可以匹配。

- **SIFT**（Scale-Invariant Feature Transform，2004，Lowe）：
  - 检测：DoG（高斯差分）尺度空间找极值 → 关键点定位（亚像素、剔除低对比度与边缘响应）。
  - 方向：梯度方向直方图 → 主方向 → 旋转不变。
  - 描述：16 个 4×4 子块、每块 8 方向梯度直方图 → **128 维 float 向量**，归一化实现光照不变。
- **SURF**（Speeded-Up Robust Features，2006，Bay）：
  - SIFT 的加速版：用积分图加速 Hessian 行列式检测，描述子用 Haar 小波响应（64/128 维）。
  - **专利**，OpenCV 中位于 `xfeatures2d` contrib 模块。本机 OpenCV 无该模块，故本工程仅讲述不实现。
- **ORB**（Oriented FAST and Rotated BRIEF，2011）：
  - 检测：多尺度 FAST；方向：灰度质心法（intensity centroid）。
  - 描述：带旋转的 BRIEF，**256 bit 二进制**，Hamming 距离匹配，极快。
- **AKAZE**（Accelerated-KAZE，2013）：
  - 用**非线性扩散**（保边）构建尺度空间，比 SIFT 的线性高斯更保细节。
  - 描述子 M-LDB 二进制，精度与速度折中。

## 背景

SIFT 是里程碑：第一次把「尺度不变 + 旋转不变 + 鲁棒描述」统一到一个完整管线，成为后续所有局部
特征（SURF/ORB/AKAZE/BRISK）对标与改进的基准。

## 解决的问题

| 算法 | 解决的问题 |
|---|---|
| SIFT | 高精度、尺度+旋转不变的特征（配准/拼接标杆） |
| SURF | SIFT 加速（专利受限，工程少用） |
| ORB | 实时、免费的特征（SLAM/EIS 首选） |
| AKAZE | 非线性尺度空间，保边、精度速度折中 |

## 效果

- SIFT 精度最高、最鲁棒，但计算慢（浮点描述 + 复杂检测）。
- ORB 最快（二进制 + FAST），精度略低，适合实时。
- AKAZE 在边缘附近精度优于 SIFT（非线性扩散保边），速度居中。

## 局限

- SIFT/SURF 浮点描述子，匹配需 L2 距离 + FLANN，算力高。
- ORB 精度对旋转/视角变化较大时下降。
- AKAZE 阈值参数敏感，二进制描述子信息量低于 SIFT。

## 后续改良

- **二进制描述子**（BRIEF/ORB/BRISK/FREAK）：大幅提速 + 降低存储。
- **深度学习特征**（SuperPoint/D2-Net 等）：现代 SfM/SLAM 逐渐用学习特征替代手工特征。
- **关键点稀疏化**：用 RANSAC/几何验证（第 7 章匹配块）剔除误匹配，弥补单点描述子精度不足。

## 实际工程使用情况

- **多摄对齐、图像拼接**：SIFT 精度最高，用于离线/高精度配准。
- **实时配准、EIS、SLAM**：ORB 是算力受限场景标配。
- **现代手机影像**：AKAZE/ORB 常见；SIFT 用于标定、拼接等离线流程。

## 对硬件的额外诉求

- SIFT/SURF 浮点运算 + 复杂金字塔，计算量大，手机上偏慢（GPU/NPU 可加速）。
- ORB/AKAZE 二进制 + 简单检测，CPU SIMD 即可实时。
- 描述子匹配（Hamming/L2）在大特征量下是瓶颈，需 FLANN 或专用硬件加速。
