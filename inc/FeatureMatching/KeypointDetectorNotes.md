# 关键点检测（Keypoint Detection）学习笔记

## 原理

关键点（角点/兴趣点）检测的目标：找到图像中**稳定、可重复定位、对几何变换和光照变化鲁棒**的点，
作为后续特征描述、匹配、配准的锚点。

- **Harris 角点**（1988）：对每个像素构造二阶矩矩阵 M（梯度协方差）：
  ```
  M = Σ w(x,y) [ Ix²   IxIy ]
               [ IxIy  Iy²  ]
  ```
  角点响应 R = det(M) − k·(trace(M))²。R 大且为局部极大 → 角点。
  R 的两项对应 M 的两个特征值 λ1、λ2：二者都大 → 角点；一大一小 → 边缘；都小 → 平坦区。

- **Shi-Tomasi（GFTT，1994）**：Harris 的改进，响应直接取 min(λ1, λ2)，比 R 更稳定，
  是 `cv::goodFeaturesToTrack` 的实现，也是光流跟踪（第 9 章）的标准选点器。

- **FAST**（2006）：取候选点周围 Bresenham 圆上的 16 个像素，若有连续 N（默认 9）个像素
  都比中心亮或暗超过阈值，则判定为角点。无方向、无尺度，但极快，是 ORB 的检测器基础。

## 背景

角点是图像中梯度在多个方向都显著变化的点，比"边缘上的点"（只在一个方向变化）信息更丰富、
更易在跨帧/跨视角下重复检测到，因此成为特征匹配与跟踪的首选锚点。

## 解决的问题

| 算法 | 解决的问题 |
|---|---|
| Harris | 检测角点（旋转不变，不尺度不变，无描述子） |
| Shi-Tomasi | 更稳定的角点选择（光流跟踪选点标准） |
| FAST | 极快的实时角点检测 |

## 效果

- Harris/Shi-Tomasi：对旋转不变，但对尺度敏感（缩放后角点响应会变）。
- FAST：速度最快，但无方向/尺度信息，需配合其它模块使用。

## 局限

- Harris/Shi-Tomasi/FAST 都**不尺度不变**：图像缩放后检测结果不稳定，需多尺度金字塔（SIFT/ORB
  的检测器解决了此问题）。
- FAST 对噪声敏感、无方向信息。
- Harris 的 k 参数（经验值 0.04~0.06）对结果敏感。

## 后续改良

- **尺度不变**：SIFT 用 DoG 尺度空间、ORB 用多尺度 FAST，解决 Harris/FAST 的尺度敏感。
- **旋转不变**：SIFT/ORB 用主方向归一化，赋予旋转不变性。
- **MSER**（2004）：检测仿射不变的稳定区域，适合文字、斑块。

## 实际工程使用情况

- **光流跟踪 / EIS 防抖 / 图像配准**：Shi-Tomasi/GFTT 是 LK 光流的选点标准。
- **实时 SLAM / 配准**：FAST（配合 ORB）是算力受限场景的首选。
- **多摄对齐、拼接**：角点是特征匹配的输入，最终配合 RANSAC 估单应。

## 对硬件的额外诉求

- 关键点检测是逐像素/邻域运算，计算量中等；Harris/Shi-Tomasi 需算梯度与特征值，FAST 只需比较。
- 手机上 FAST/ORB 可用 SIMD 加速到实时；Harris/Shi-Tomasi 稍重，但也在 GPU/ISP 可负担范围。
