# 特征匹配 + RANSAC（Feature Matching & RANSAC）学习笔记

## 原理

特征匹配把两幅图的描述子配对，RANSAC 进一步剔除误匹配并估计几何变换。

- **暴力匹配（BruteForce）**：对图 1 每个描述子，与图 2 所有描述子逐一算距离（L2 或 Hamming），
  取最近者。精确但 O(N·M)。
- **FLANN**：近似最近邻（KD-tree / KMeans 树），大数据量下显著加速，结果是近似的。
- **Lowe's ratio test**：对每个描述子取最近邻与次近邻，若 `d1 < ratio·d2` 才保留。
  思想是"好的匹配应该是唯一的"，能剔除大量歧义匹配（ratio 常取 0.7~0.8）。
- **交叉验证（cross-check）**：双向匹配一致才保留，进一步提纯。
- **RANSAC**（RANdom SAmple Consensus，1981）：
  1. 随机抽最小子集（单应需 4 对）估模型 H；
  2. 用 H 检验所有点，统计内点（重投影误差 < 阈值的点）；
  3. 重复 N 次，取内点最多的 H 作为最终估计。
  鲁棒地抵抗外点（误匹配），是配准/拼接/极几何估计的核心。

## 背景

特征匹配是「图像对应关系」的桥梁：从两图的描述子建立点对应，再由几何验证剔除误匹配、估计变换。
这是图像拼接、配准、三维重建、SLAM 的共同地基。

## 解决的问题

| 技术 | 解决的问题 |
|---|---|
| BF / FLANN | 建立描述子对应 |
| ratio test / cross-check | 剔除歧义匹配 |
| RANSAC | 鲁棒估计几何变换（单应 H / 基础矩阵 F），抵抗外点 |

## 效果

- ratio test + RANSAC 组合能把「含大量误匹配」的原始匹配提纯到「几乎全是正确匹配」的内点集。
- RANSAC 对 50% 甚至更高比例的外点仍能稳定收敛。

## 局限

- RANSAC 的迭代次数 N 与外点比例相关：外点越多，需更多迭代才能大概率命中全内点子集。
- 阈值（重投影误差）选择敏感：太大纳入外点、太小剔除真内点。
- FLANN 是近似匹配，对二进制描述子（ORB/AKAZE）不如 BFMatcher 直接。

## 后续改良

- **LMEDS**（最小中值平方法）：抗 50% 外点，无需阈值。
- **PROSAC**：按匹配质量排序抽样，收敛更快。
- **RANSAC 变体**：MSAC、MLESAC 等改进内点打分。
- **图匹配 / 深度匹配**：现代方法用图优化或学习特征提升匹配精度。

## 实际工程使用情况

- **图像拼接**：ratio test + RANSAC 估单应 H，是多幅图拼接的标配。
- **多摄对齐**：RANSAC 估 H 实现跨摄像头图像对齐。
- **双目深度 / SfM**：RANSAC 估基础矩阵 F / 本质矩阵 E（第 11、12 章地基）。
- **EIS 防抖**：RANSAC 估帧间单应/仿射，稳定视频。

## 对硬件的额外诉求

- 匹配（尤其 BF）是计算密集，大特征量下需 FLANN 或 GPU 加速。
- RANSAC 迭代 + 每次全量内点统计，外点多时算力高，但整体可控。
- 手机上实时配准通常用 ORB + BFMatcher(Hamming) + RANSAC，CPU 可实时。
