# 视频插帧（Frame Interpolation）学习笔记

## 原理

视频插帧在两帧之间合成中间帧，提升帧率（慢动作/补帧）。

经典流程（`FrameInterpolator` 实现）：
1. **双向光流**：计算 prev→curr（前向）和 curr→prev（后向）两张光流场。
2. **光流后处理**：guided filter 平滑、一致性掩码、遮挡检测。
3. **运动补偿**：用前向/后向光流分别把两帧 warp 到中间时刻 t，得到两个候选中间帧。
4. **融合**：按光流置信度加权 + 拉普拉斯金字塔融合，合成最终中间帧。

关键参数：`t ∈ (0,1)` 是插值位置（0.5 = 正中间），越接近 0 越像 prev。

## 背景

插帧是光流最直接的应用之一，也是手机影像（慢动作、高帧率视频）的核心功能。它把「运动估计」和
「图像合成」结合起来。

## 解决的问题

| 技术 | 解决的问题 |
|---|---|
| 视频插帧 | 提升帧率（慢动作、补帧） |
| 双向光流 | 准确估计中间时刻的运动 |

## 效果

- 对平移/小运动，插帧质量高。
- 双向光流 + 一致性掩码能处理遮挡。

## 局限

- 大位移、复杂形变、遮挡边缘处插帧质量下降（鬼影）。
- 依赖光流精度：光流错 → 插帧错。
- `t ∈ (0,1)` 开区间，端点会退化/断言。

## 后续改良

- **深度学习插帧**（RIFE/DAIN）：精度远超传统光流法，是当前主流。
- **多尺度 + 遮挡推理**：处理复杂运动。
- **自适应 t**：按运动复杂度调整。

## 实际工程使用情况

- **手机慢动作/高帧率**：插帧是核心算法。
- **视频修复/超分**：配合插帧。
- **光流应用**：插帧是光流的 benchmark。

## 对硬件的额外诉求

- 光流计算是瓶颈，DIS 后端可实时；深度学习插帧需 NPU/GPU。
- 手机上传统插帧用 DIS + 专用加速，深度学习插帧用 NPU。
