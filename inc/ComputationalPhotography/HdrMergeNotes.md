# HDR 融合（High Dynamic Range Merging）学习笔记

## 原理

HDR（高动态范围）解决「普通相机单次曝光无法同时记录亮部与暗部细节」的问题。通过**多张不同曝光**
的图，合成一张动态范围更大的 HDR 图，再色调映射回 LDR 显示。

工程实现双管线：

- **Mertens 融合**（`MergeMertens`）：对每张图按**对比度、饱和度、曝光度**三权重做多尺度融合，
  直接得到 LDR 结果。无需标定响应曲线，简单鲁棒。
- **物理 HDR 管线**（`MergePhysicalHdr`）：更严谨的流程——
  1. 对齐（`AlignToReference`）
  2. sRGB 去伽马 → 线性光
  3. 标定相机响应曲线（`CalibrateDebevec`）+ 曝光时间
  4. `MergeDebevec` 合成真 HDR 32F
  5. 色调映射（`TonemapHdr`，Drago/Reinhard）回 LDR

**鬼影抑制**：多曝光拍摄时场景运动会产生鬼影，工程用 LK 光流（`DetectMotionLk`）或帧差
（`DetectMotionDiff`）检测运动区域并抑制。

## 背景

HDR 是计算摄影的经典课题。手机「多帧 HDR」是其直接应用——连续拍多张不同曝光，融合出兼顾
亮暗细节的照片。

## 解决的问题

| 技术 | 解决的问题 |
|---|---|
| 多曝光融合 | 扩展动态范围（同时记录亮暗细节） |
| 色调映射 | 把 HDR 压缩到 LDR 显示 |
| 鬼影抑制 | 消除运动区域的融合伪影 |

## 效果

- 高对比场景（逆光、夜景）能保留亮暗细节。
- 物理管线比 Mertens 更保真（真 HDR + 响应曲线标定）。

## 局限

- 需要多张不同曝光，且帧间对齐（手持会抖动）。
- 运动物体产生鬼影（需鬼影抑制）。
- 色调映射参数敏感（Drago 的 gamma/saturation 等）。
- Mertens 是近似，不做真 HDR，动态范围扩展有限。

## 后续改良

- **曝光补偿 + 渐晕校正**（第 8 章）作为对齐前的预处理。
- **深度学习 HDR**：CNN 直接从 LDR 序列重建 HDR，处理鬼影更鲁棒。
- **RAW 域融合**：在 RAW 域融合（线性、无去马赛克损失），现代手机主流。

## 实际工程使用情况

- **手机多帧 HDR / 超级夜景**：核心算法。
- **相机包围曝光合成**：专业相机的 HDR 模式。
- **计算摄影**：与多帧降噪（MFNR）配合，夜景 = HDR + 降噪。

## 对硬件的额外诉求

- 多帧对齐（特征匹配）+ 融合 + 色调映射，算力中等。
- 物理管线（Debevec 标定 + 32F 合成）比 Mertens 重，需 GPU/ISP 加速。
- 手机 HDR 在 ISP 或 NPU 上做 RAW 域融合，实时出片。
